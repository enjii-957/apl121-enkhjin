# APL121 Бие даалт №1: Code Quest

- **Сэдэв:** №7 Тоо таах тоглоом
- **Оюутан:** Н.Энхжин
- **Бүлэг/Анги:** [1-12]
- **GitHub Repositories:** [apl121-enkhjin](https://github.com/enjii-957/apl121-enkhjin)

## Тоглоомын дүрэм ба тогтоосон хязгаарлалт
1. Компьютер 1-ээс 100 хүртэлх санамсаргүй тоо санах бөгөөд тоглогч тухайн тоог таахыг оролдоно.
2. Оролдлого бүрт компьютер «их» эсвэл «бага» гэсэн зөвлөгөө өгч чиглүүлнэ.
3. Тоглоход хамгийн ихдээ **7 удаагийн оролдлого** хийх эрхтэй.
4. Сүүлийн 3 тоглолтын үр дүнг хооронд нь жишиж эрэмбэлэн хүснэгт хэлбэрээр харуулна.
5. Хүрээнээс гадуур таамаг (1-100-аас гадуур) оролдлогод тоологдохгүй.
6. Хожигдсон тоглолтыг 7 оролдлого гэж бүртгэнэ.
7. Оролдлого 4 ба түүнээс бага бол «Сайн», бусад тохиолдолд «Дунд» гэж ангилна.

## Ажиллуулах команд (GCC)
Терминал дээр дараах тушаалыг ашиглан компайл хийж ажиллуулна:
```
gcc main.c -o guess_game
./guess_game
```
Flowgorithm: `quest.fprg`-г нээгээд **Run** дарна.
